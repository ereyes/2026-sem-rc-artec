# Séminaire de recherche-création — 2026

Ce dépôt réunit trois réalisations issues du séminaire **Méthodes visuelles et performatives pour la recherche-création et l’écriture créative** de **Louis-Claude Paquin**, en **octobre–novembre 2026** : un collage, une écriture performative et une carte heuristique.

## Consulter les réalisations

Les liens ci-dessous ouvrent les résultats dans le navigateur via [GitHub Pages](https://ereyes.github.io/2026-sem-rc-artec/).

### 1. Collage — Coastlines, Atlas des côtes

Une mosaïque interactive de 42 vues cartographiques de littoraux.

**[Ouvrir le collage interactif](https://ereyes.github.io/2026-sem-rc-artec/collage/)**

Version image : [voir le collage exporté (JPEG)](https://ereyes.github.io/2026-sem-rc-artec/collage/collage001.jpeg).

Fichiers du projet : [`collage/`](https://github.com/ereyes/2026-sem-rc-artec/tree/main/collage).

### 2. Écriture performative — Water voices

Une écriture performative interactive autour des sons et des mouvements de l’eau, associant mots animés et voix en cinq langues.

**[Ouvrir Water voices](https://ereyes.github.io/2026-sem-rc-artec/water-voices/)**

Fichiers du projet : [`water-voices/`](https://github.com/ereyes/2026-sem-rc-artec/tree/main/water-voices).
